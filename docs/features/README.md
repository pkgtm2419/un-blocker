# Feature behavior guides

Human-owned, code-grounded feature contracts. Each describes current source paths and regression targets, **not a promise of successful device testing**. Add new guides and rows to [feature matrix](../FEATURE_MATRIX.md) as features land. Behavior-changing PRs must update affected guides and generated inventory in the same branch.
