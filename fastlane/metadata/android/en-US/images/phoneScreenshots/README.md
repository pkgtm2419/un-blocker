# Phone Screenshots

Place at least 3 phone screenshots (PNG, ≤8 MiB each) here before submitting to F-Droid or IzzyOnDroid.

Recommended shots:
1. Home screen — VPN protection active
2. Logs screen — recent activity with blocked domains
3. Settings screen — section overview

Screenshots are used by F-Droid and the Play Store metadata pipeline. File names do not matter; order is alphabetical.
